Measured from the code, not the screenshots

Layout 6 = FSSAI: food badge beside the name at 15 px, list-only, no view toggle. Card glyphs 24 px; item-page glyphs 35 px (top_button_text_font_size × 2.5); Nutrition Facts centred in ItemAdvisoryRow, 2px 8px, 4 px radius, no border, no glyph.

The allergen glyphs are ITC's own, in ITC's own colours

Bukhara has a custom icon set — icon_set.name: "ITC", 18 glyphs, served from assets.mydigimenu.com/icon-set/icon_itc.json — and it is fixed_color: true. Every path ships its own fill, so the theme's colour prop never reaches the artwork: wheat is #C63C2A, fish is #2D4495, egg is grey and peach. Those are the real paths, rendered here at the real sizes. Only the chip's label takes a theme colour — grid_view_button_background_color on a card, top_buttons_background_color on the item page.

The Nutrition Facts button carries no glyph because ic_nutrition_info is in neither the bundled set nor ITC's own 18 — which is exactly what the live screenshot shows. If ITC wants an icon there, the glyph has to be added to their set first.

Checked against source. Layout, element order and every size below came from the components, not from the screenshots: layouts.js (ITC is layout 6, FSSAI), ModernListCard + FssaiListCard for the menu card, ItemAdvisoryRow for the Nutrition Facts row, ItemAllergenRow for the item-page chips, AllergenStrip for the card chips, foodTypeBadge.module.scss for the 15 px mark, and PriceCaption for the 75%-of-price caption. The allergen artwork is ITC's own IcoMoon paths from icon_itc.json, fills included.

About the numbers. Dish names, descriptions, prices, photos, per-serve weights, calories and allergens are the live Signature Menu. Bukhara has not yet filled in the detailed nutrition fields, so the macro and micronutrient figures here are modelled from each dish's real calorie count and serve weight purely to show the layout — every drawer carries a “sample values” marker. Once the kitchen's real figures are entered in the panel they flow straight into this layout with no further design work.
